# FORMA Studio — Design Guidelines

## Stance
Editorial dark. A design studio website that reads like a high-quality print publication, not a SaaS product. Every decision reinforces confidence and restraint.

## Typography
- **Display / Headings**: Fraunces (variable optical serif — use light/300 weight, italic for expressive moments)
- **Body / UI**: Outfit (geometric sans — 400 for body, 500 for labels and buttons)
- **Mono / Labels**: DM Mono — section numbering, data, metadata tags

## Color Palette
- Background: `#0A0A0A` — deep near-black canvas
- Foreground: `#EAE6DE` — warm off-white/cream
- Card: `#111111` — slightly lifted surface
- Secondary: `#1C1C1C` — subdued panels and hover states
- Accent: `#C8420D` — terracotta/rust, used sparingly for emphasis
- Muted foreground: `#6E6B66` — captions, secondary labels
- Border: `rgba(234,230,222,0.08)` — hairline rules

## Radius
`0rem` — sharp corners throughout. Softness comes from typography and spacing, not rounded edges.

## Layout Principles
- Asymmetric 12-column grid for page-level structure
- Section numbers in DM Mono (`01 /`, `02 /`) as anchors
- Generous vertical rhythm: sections breathe
- Project grids alternate 7/5 column splits to avoid uniformity

## Image Treatment
- Grayscale with reduced opacity on ambient/atmosphere images
- Full color on featured project work
- Dark gradient overlays on hover states
- Always include descriptive alt text
